# 参与贡献

欢迎提交问题报告和改进。提交前请先确认改动符合 macOS 14.6+、本地优先和 Codex / Claude Code 的项目范围，并在问题或变更说明中写清复现条件、影响范围和验证方式。

不要提交真实会话、凭据、Cookie、Prompt、回复、源代码片段或包含个人绝对路径的日志。需要示例数据时，请使用自行编写的匿名样本。修改 Provider 解析、SwiftData 模型、额度语义或 Widget 共享格式时，请说明兼容与迁移影响。

1.0.0 的构建、测试及真实来源联调结果应分别如实记录；未执行的验证不要标为通过。安全漏洞请遵循 [SECURITY.md](SECURITY.md) 的私下报告方式。
