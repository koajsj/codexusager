## 范围

## 数据与错误处理

- fallback ID：SHA256 覆盖 provider/session/规范化时间/model/input/cacheRead/cacheWrite/output/reasoning/total/eventType，长度前缀防止分隔符碰撞。有源事件 ID 时继续优先使用。导入时先注入 turn_context model，跨格式合并也比较 model。
- 旧游标 revision 2 升至 3，首次重索引恢复过去被误去重的不同事件。只对能与旧原始值明确匹配的人工修正重绑新 ID，不覆盖目标已有修正；无法匹配的修正保留。原始 Session 文件只读，SwiftData schema 未改变。
- Claude spend_limit：有限非负 used 可以超过 100，remaining 归零；five_hour/seven_day 仍限制 0–100。统一校验覆盖当前状态、缓存读取、历史和备份，QuotaRow 明示已用百分比/已超出限额。
- Codex 401/403 要求重新连接。quota 的 -32603 触发 account/read 再确认；成功则保留服务不可用提示，缺失/失败则显示可能失效并提供重新连接。只保存操作名与错误类型，不显示/记录远端 error data。
- quota 保存时移除 raw accountID；启动时清除旧 account/Quota 中不必要原始标识，保留哈希绑定。JSONRPC initialize 从 Bundle 读取实际版本，无 Bundle 时使用 unknown。

## 刷新与性能

- RefreshViewModel 拥有 polling Task，RefreshSchedule 保存尝试时间及调度判定。AppModel 保留生命周期和高级协调；不引入新框架。
- 菜单栏先展示缓存，成功更新时间超过 5 分钟才仅刷新 quota，已有刷新则合并；手动菜单操作也只刷新 quota。
- 主窗口不活跃时暂停周期 JSONL 扫描，额度轮询继续；启动与手动索引保持。Streaming/增量游标和取消检查保留。
- Claude 绑定缓存只保存 hashed accountKey 与 timestamp，TTL 15 分钟；凭据变更元数据、环境与配置无法确认则不缓存。Keychain 只查属性且禁止交互，不读取 credential 值。
- ProcessRunner 区分 missing/timeout/cancellation/nonzero。异步输出队列与总输出有界；取消主动 TERM，仍存活的同一 child 一秒后 KILL。测试确认忽略 TERM 的子进程被清理。

## UI

保持 Dashboard 和最近 5 条布局。菜单栏去掉自动激活主 App，动态文字测量包含真实百分比；大数使用格式化显示避免 Int 转换陷阱。Sources 增加 resolved executable 路径；统一连接/服务错误标签。主窗口刷新添加 ⌘R。BrowserLoginFeedback 原有 loopback/no-store/CSP/转义/短生命周期保持。
