# 变更记录

## Unreleased — Tahoe Analytics

- 当前源码最低 macOS 版本调整为 26.0；App、Widget、Bridge、SwiftPM 与 CI 检查统一。
- 复用既有存储与单价，增加活动中心、模型调用指标、成本覆盖率、项目常用模型及日/周/月和小时分析。
- 修复缺失 Total 推算、跨批次错误丢失、失败扫描成功时间、分页排序、极值平均数与夏令时小时分桶。
- Codex 实时观察与历史 Token 分离；Widget 相同状态避免重复写入及 reload。
- 手动记录查询与导出遵守原始项目的忽略规则；Provider 对比不将不完整 Total 当成完整消耗；覆盖导出文件时保持仅当前用户可读写权限。
- 旧版本数据库迁移测试与并行分析测试隔离，避免 SwiftData 进程内模型缓存冲突。
- 统计与来源摘要增加数据变更失效缓存，筛选查询复用独立首页口径并下推日期 / Provider 条件；处理时区、时钟和日期边界。
- 活动中心改用固定截止时间与数据版本的游标分页，搜索防抖、保留旧结果，减少重复查询；窗口按实际内容宽度适配，首页突出额度、今日 Token 与趋势。
- main / PR 增加独立 CI。发布脚本检查 App / Widget 团队、App Group 和签名配置；未签名流程仅允许 Preview Tag，DMG 复用统一脚本。
- 未执行真实登录、启动 UI 或发布新安装包；数据来源限制见 README。

## 1.0.1-preview

- 修复 fallback 指纹遗漏 model、reasoning、total 导致的误去重，升级解码器游标版本，安全重索引并保留可匹配人工修正。
- Claude 消费限额允许超过 100%（剩余归零），限时窗口仍严格校验；超额支持持久化、历史、备份和明确 UI 提示。
- Codex 内部 RPC 失败后重新确认账户；区分可能失效登录与临时服务故障，不保留远端错误正文。
- 菜单栏仅检查额度 freshness；后台保留轻量额度刷新，主窗口不活跃时暂停周期性 JSONL 索引。
- Claude 桥接增加 15 分钟哈希账户绑定缓存；凭据元数据不可确认、账号变更或特殊认证环境时不复用。
- 子进程超时、取消、非零退出和未安装分开处理，取消支持 TERM / KILL 清理，输出队列有界。
- 持久化清除不必要的原始 accountID；备份白名单及模拟敏感标记回归检查。
- Release CI 增加测试门禁、生成器一致性检查、固定 Actions SHA 和 Xcode 26.6。
